# Roadmap

Pull Syndicate is the vendor and community brand at [https://pullsyn.co](https://pullsyn.co). A future collectibles software app is a **separate brand** with a partnership/licensing relationship only.

## Phase 1 — Brand website (this sprint)

Design system, navigation, optional cinematic intro, homepage, About, Community, Events, Contact, responsive layouts, SEO, Phase 1 Supabase tables, GitHub Actions, GitHub Pages on `pullsyn.co`.

Success: a fast, accessible public brand site that can take enquiries and list events.

## Phase 2 — Commerce

Products, categories, product pages, search (Cmd/Ctrl+K), cart (guest local + auth sync), Stripe, orders. Server-authoritative prices. PETG deck boxes become real SKUs.

## Phase 3 — Admin

Protected `/admin`: revenue, orders, products, inventory, customers, events, homepage featured content. Image uploads. Fulfilment and tracking.

## Phase 4 — Accounts

Supabase Auth (email/password, optional Google). Profile, orders, addresses, preferences, My Vault (wishlist architecture that can later connect to the separate app).

## Phase 5 — Advanced experience

Heavier cinematic motion only if Core Web Vitals stay healthy, personalisation, collector tools, app partnership hooks.

## 90-day business alignment

From the internal partnership blueprint (not committed to this repo):

- Days 1–30: company formation and books (off-site).
- Days 31–60: launch the simple PullSyn.co site (Phase 1).
- Days 61–90: prepare ecommerce (Phase 2).

## Quality bar

Nike-style brand presentation + TCG/LEGO collector culture + high-end ecommerce later. The cinematic layer supports products. It does not replace usability.

Must stay: fast, accessible (WCAG 2.2 AA target), responsive, secure, easy to shop, easy to maintain.
